观察：整码是否只落进第 1 格

KNOWN FAILURE MODES · 本页该观察到什么
  • 分格输入通常只有第一格带 one-time-code，安卓会把整码塞进第一格，出现"1 格里 6 位数"的已知现象。
  • WebOTP（OTPCredential）只走 HTTPS + 真实短信域名校验，本地 http 不会触发；此处仅登记 API 可用性。
  • inputmode=numeric + pattern + maxlength=1 的组合会阻止某些管理器写超长值。
