INTERPRETATION · 怎么读这些事件
  • FILLED：收到 trusted 的 input 事件，且该输入框在 800ms 内没有键盘事件 → 值来自外部（管理器 / 系统建议 / 复制粘贴的替换）。
  • SILENT-FILL：值变了但一个 input 事件都没有（轮询发现）。某些管理器直接改 .value 并派发 untrusted 事件，或干脆不发事件。这是最容易漏检的填充。
  • CSS :-webkit-autofill 命中：浏览器自己标记了自动填充态，独立于事件。与 FILLED 同时出现最可信；只出现这一条说明值由浏览器内部状态驱动。
  • SCRIPT：isTrusted = false，是页面脚本写的，不算管理器填充（本页的动态插入 / 格式化脚本可能制造这种噪声）。
  • TYPED：键盘输入。做对照时先手输一部分，能验证 CHECK 逻辑本身没问题。
  • SUBMIT：默认被拦截，所以不会产生保存提示。要测保存提示请回表单页勾选“允许真导航”。
  • 只有 FOCUS、没有 FILLED：管理器根本没识别出可填字段，或本机没存匹配条目 —— 先看那页的 KNOWN FAILURE MODES。
