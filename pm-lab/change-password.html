NOTES · 本页说明

三个密码框同页：current-password → new-password → new-password。这是"填了哪个、存了哪个"最难分辨的场景。

  • 第一个必须是 current-password，后两个 new-password。写错会让管理器把新密码填进旧密码框。
  • Chrome 只在最后一个 password 字段显示建议图标，看起来像"没填上"，其实是 UI 行为。
  • 修改成功后应当保存新密码；若你的管理器更新了旧条目，说明它按 DOM 顺序猜的，而不是按 autocomplete。
