NOTES · 本页说明

没有 autocomplete 时，实现只能读 name/id 关键字。这里用 12 种真实世界出现过的写法，包括把密码放在 type=text 里的移动端骗术。

  • pwd / upwd / pass / user_name / login_email 这类缩写命中靠字典；字典里没有的实现就完全不填。
  • type=text 冒充密码框（iOS 常见：为避免系统键盘遮挡而用 text + 自定义掩码）会让管理器认不出这是密码字段——这是可预期失败。
  • name 带中文/全角 与 name 是 UUID 是启发式的两个死角。
